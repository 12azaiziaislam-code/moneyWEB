# Human Design

## Goal
Deliver interfaces that look and read as if a skilled human designer and developer made them. No trace of AI generation, visible or hidden.

## Part 1: Remove literal AI markers (always run on every project)
Search the whole project (HTML, JSX/TSX, CSS, JS, config, README, package.json, public/, assets, metadata) and remove:
- `<meta name="generator" ...>` and any tool/platform generator tags.
- Badges, footers, watermarks or links such as "Built with / Made with / Powered by / Generated by" followed by any AI tool, builder or model name.
- Comments revealing generation: "Generated by", "As an AI", "Here is the code", "TODO: replace with real content", "Claude", "ChatGPT", "Gemini", "Copilot", "v0", "Lovable", "Bolt", "Cursor", and similar.
- Default descriptions in package.json, README, manifest, and <title>/<meta description> left from templates.
- Placeholder content: lorem ipsum, "John Doe", "Acme Inc.", "example@example.com", "Your Company", fake phone numbers, fake testimonials, invented statistics, fake logos.
- Default or template favicons, OG images and app icons. Ask me for real ones or create neutral custom ones.
- Over-explanatory code comments that narrate obvious code. Keep only comments that explain WHY.
- Leftover console.log, debug text, and unused boilerplate files.
Do NOT remove legally required license notices or attributions of third-party libraries.

## Part 2: Avoid the "AI look" (visual tells)
Never use these unless I explicitly ask:
- Purple/blue/pink gradients, gradient text, glowing blurred blobs, neon glow.
- Glassmorphism and heavy backdrop-blur on everything.
- Emojis used as icons or bullets.
- The default layout: centered hero + two buttons + row of three identical icon cards + stats row + CTA banner.
- rounded-2xl and large soft shadows on every element.
- Inter / Roboto / system default as the only font choice without a reason.
- Perfect symmetry and identical spacing everywhere.
- Fake social proof, fake counters, "trusted by 10,000+ teams".
- Mixed random icon styles. Use one consistent icon set or custom SVGs.

## Part 3: Design like a human
1. Before coding, write a short design brief: audience, tone, 3 adjectives, one memorable idea.
2. Choose a restrained palette: 1 dominant color, 1 accent, neutrals, defined as CSS variables. Check contrast (WCAG AA).
3. Choose a deliberate type pair and a real type scale. Vary weight and size to create hierarchy.
4. Use varied layout rhythm: asymmetry, different section structures, generous whitespace, a clear grid.
5. Use real content provided by me. If missing, ask for it instead of inventing it.
6. Motion: subtle and purposeful only (hover, reveal, focus). Respect prefers-reduced-motion.
7. Details: consistent border radius system, consistent spacing scale, real focus states, empty and error states.
8. Responsive from mobile first, tested at 360, 768, 1280 px.

## Part 4: Copywriting
- Write plain, specific, direct sentences in the brand's voice.
- Ban filler words: revolutionize, unlock, seamless, elevate, empower, leverage, cutting-edge, game-changer, "in today's fast-paced world", "dive in".
- Avoid overusing em dashes, triplets ("fast, simple, powerful"), and rhetorical questions in headings.
- Arabic: write natural modern Arabic, not literal translation. Avoid stiff marketing clichés.

## Part 5: Arabic / RTL
- Set dir="rtl" and lang="ar" when the site is Arabic.
- Use CSS logical properties (margin-inline-start, padding-inline, text-align: start).
- Use quality Arabic fonts (Cairo, Tajawal, IBM Plex Sans Arabic, Noto Naskh/Kufi) with proper line-height (1.7+).
- Mirror directional icons and layouts correctly.

## Final audit (mandatory before finishing)
Run searches for: generator, "made with", "built with", "generated", lorem, "john doe", "example.com", claude, chatgpt, openai, gemini, copilot, lovable, bolt, "v0". Fix every hit. Then give me a short report listing what was removed and what remains.
